# Compact FE dataset generation

The compact data files were generated by streaming over each original `RESULTS_*.csv` inside the two supplied ZIPs. Each file contains six stress components at columns 15-20 (one-based). The retained row is the one maximizing

`vm^2 = ((sxx-syy)^2 + (syy-szz)^2 + (szz-sxx)^2)/2 + 3*(sxy^2+syz^2+sxz^2)`.

This matches the maximum-von-Mises selection used by the supplied calibration and prediction scripts. The entire selected 20-column CSV row is retained without numerical rounding. `data/fe_node_selection.csv` records a manifest of selections and original row counts. The original test `.txt` files were copied byte-for-byte.
