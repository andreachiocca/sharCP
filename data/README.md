# Data supplied with the scripts

The `calibration/` and `validation/` directories contain **experimental fatigue-life text files and one selected FE hotspot row** for each original `RESULTS_*.csv` input. Folder names and input-file layouts are preserved.

The source FE archives contained up to hundreds of thousands of nodal records per dataset. All six supplied analysis scripts select the **highest-von-Mises-stress node** from each `RESULTS_*.csv` file. To make the repository manageable, only that selected record was retained, including all 20 original columns (node, load step, elastic strains, zero-padded fields and stress tensor). The retained row therefore produces the same script-selected input tensor under the current selection logic. All other nodes and any unreferenced duplicate CSVs have been excluded; this is **not** a full FE dataset and cannot support changing the hotspot selection or assessing nearby nodes.

`fe_node_selection.csv` reports the selected node and the number of original FE nodes for every file. Exact source archives were `Calibration_results(1).zip` and `Prevision_results(1).zip`, provided by the author.

**Important:** The six criterion-specific `slopes_vs_alpha_*.dat` mapping tables are now included in both `calibration/` and `validation/`. The precomputed fitted master-curve files (`powerlaw_fit_*_all.tex`) were **not present** in the supplied archives; these can be regenerated by the calibration scripts, subject to the documented calibration settings. See `docs/REPRODUCIBILITY.md`.

Some original experimental measurements are from published literature. Check original source terms and citations before redistributing full raw experimental archives. This repository's MIT license applies to software, not automatically to third-party fatigue-test measurements.
