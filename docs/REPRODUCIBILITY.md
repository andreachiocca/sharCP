# Reproducibility, inputs and limitations

## What is contained here

- Calibration and prediction scripts supplied for Fatemi–Socie (FS), Findley (FI) and Smith–Watson–Topper (SWT).
- Calibration/validation experiment files (`*_R_*.txt`), retaining their original naming and stress ratios.
- Reduced linear-elastic FE stress/strain input files (`RESULTS_*.csv`) preserving the selected maximum-von-Mises row, along with a selection manifest.
- Unique FE postprocessing helper scripts found in the calibration archive (`tools/legacy_fe_postprocessing/`).

## Coefficient lookup tables and calibration inputs

All six criterion-dependent equivalent-radius lookup tables are included in `data/calibration/` and `data/validation/`.

| Criterion | Mode I (half-angle, plane stress, plane strain) | Mode III (half-angle, antiplane) |
|:--|:--|:--|
| FS | `slopes_vs_alpha_fs_modeI.dat` | `slopes_vs_alpha_fs_modeIII.dat` |
| FI | `slopes_vs_alpha_findley_modeI.dat` | `slopes_vs_alpha_findley_modeIII.dat` |
| SWT | `slopes_vs_alpha_swt_modeI.dat` | `slopes_vs_alpha_swt_modeIII.dat` |

The first column is the notch half-opening angle in degrees. The following columns contain the equivalent-radius factor used by the corresponding critical-plane criterion. The files retain the author-supplied numeric data and filenames. The predictor also requires criterion-specific fitted master-curve macros `powerlaw_fit_*_all.tex`, which are generated by the calibration scripts and are not included as independently verified publication outputs.


## Input details

- Author folder names encode reference notch radius and yield stress, for example `Bertini__1__355`.
- Mode I folders use `Modo_I` for calibration and may use `Mode_I_pstress`/`Mode_I_pstrain` for validation; Mode III folders use `Modo_III`.
- Results file names encode TOE/ROOT and the notch **half-angle**, e.g. `RESULTS_TOE_67_5.csv`.
- `*_R_*.txt` files encode nominal experimental load ratio. Stress/strain data are from a linear-elastic FE reference analysis for a code-defined unit load of 1000 N mm.

## Important methodological cautions

1. The supplied calibration scripts have a single `--planeI` (FS/FI) or `--plane` (SWT) **global** Mode I plane-stress/plane-strain option. The article discusses geometry-dependent assignments. Thus the scripts as provided do not automatically enforce the paper's per-geometry PS/PE assignments. Before claiming exact article reproducibility, check and adapt the mapping selection for each calibrated geometry; do **not** change assumptions silently.
2. The scripts currently pick an FE node by maximum von Mises stress, which is not necessarily the same as choosing the node with the highest evaluated critical-plane parameter. Full FE fields would be needed to compare the selection rules.
3. The supplied implementation addresses Mode I and Mode III analytical mappings with linear elasticity and proportional loading. Mode II, mixed mode and non-proportional history support are not established.
4. Calibration and validation may rely on historical source data and different fatigue-life stopping definitions. Interpret any pooled fatigue-life statistics accordingly.
5. FE node CSVs in this repository are deliberately reduced. They are sufficient to exercise the scripts' current hotspot-selection code but **not** to audit stresses along the weld, rerun FE, change the node-selection method, or recover the full FE field.
6. **The full numerical results published in the article have not been independently regenerated with this package**, because the original run parameters and complete FE data are not supplied. Do not advertise exact numerical reproduction until an end-to-end run is completed with the same source files and settings.

## Full-source archives

Keep `Calibration_results(1).zip` and `Prevision_results(1).zip` separately as research archives. The prediction archive contains an individual CSV larger than GitHub's 100 MB file limit; Git LFS, a release asset, or a research data repository is more appropriate for the complete nodal exports. The reduced dataset is provided to keep the source repository lightweight.
